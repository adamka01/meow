    Cloud Sync

    Sync your tasks across all your devices with a free Supabase database. Leave this off to keep tasks on this device only.

    How do I set this up? (one-time, ~5 min)
    1. Go to supabase.com and sign in (free — you can use your GitHub account).
    2. Click New project, give it a name and database password, and wait ~2 min for it to start.
    3. Open SQL Editor in the left sidebar, paste the snippet below, and click Run: 
      create table if not exists tasks (
  id text primary key,
  list_code text not null,
  text text not null,
  done boolean not null default false,
  priority text not null default 'med',
  due text not null default '',
  created bigint,
  position double precision not null default 0
);
create index if not exists tasks_list_code_idx
  on tasks (list_code);
alter table tasks enable row level security;
create policy "public list access" on tasks
  for all to anon using (true) with check (true);
alter publication supabase_realtime add table tasks;
    4. Open Project Settings → API. Copy the Project URL and the anon / publishable key into the fields above.
    5. Click New to make a list code, then Connect & Sync.
    6. On your other devices, open this app, enter the same URL, key, and list code — done!

    Note: the list code acts like a password — anyone who has it (plus your URL & key) can see this list, so keep it private.
